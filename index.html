📅 設定行事曆提醒
🔒

需要先登入雲端同步，才能使用行事曆提醒功能。

已設定到期日或學習排程的課程，開啟訂閱後就會自動出現在手機日曆裡，提醒交給日曆 App 處理；沒設定的課程不會出現。新增課程後，日曆會在幾小時內自動跟上，不用手動重新匯出。

你要用哪一種日曆？

手動加入或自動加入失敗？
第一步：啟用訂閱連結

點上面的「啟用行事曆提醒」，選擇你的日曆種類，再點「點此自動加入行事曆」。

第二步：加入手機日曆

如果自動加入沒有反應，點下面對應的按鈕複製連結，改用手動的方式加入：

已複製 Apple 日曆的訂閱連結。打開 Safari，貼到網址列按 Enter（或貼在備忘錄／訊息裡點一下），會跳出「訂閱這個行事曆嗎？」的視窗，按「訂閱」即可。之後打開「日曆」App 就能看到。

已複製 Google 日曆的訂閱連結。電腦開 calendar.google.com → 左側「其他日曆」旁的 + → 「透過網址訂閱」→ 貼上連結 → 新增日曆。手機上的 Google 日曆 App 會自動同步顯示。

第三步：設定提醒時間

提醒方式、提前多久提醒（前 10 分鐘、前一天都行），都是在手機日曆本身的設定裡調整，跟設定其他行事曆活動一樣。日曆通常每幾小時自動刷新一次，新增課程後不會馬上出現，但幾小時內會自動跟上。

☁️ 雲端同步

要跨裝置同步，需要接一個免費的 Supabase 雲端資料庫（你自己的帳號，個人用量完全在免費額度內）。設定步驟：

1. 到 supabase.com 免費註冊，建立一個新專案
2. 進專案的 SQL Editor，貼上以下指令執行一次（建立資料表＋權限規則）： 

create table app_state (
  user_id uuid primary key references auth.users(id) on delete cascade,
  data jsonb not null default '{}'::jsonb,
  share_token uuid,
  share_enabled boolean not null default false,
  updated_at timestamptz not null default now()
);
alter table app_state enable row level security;
create policy "select own" on app_state for select using (auth.uid() = user_id);
create policy "insert own" on app_state for insert with check (auth.uid() = user_id);
create policy "update own" on app_state for update using (auth.uid() = user_id);

create or replace function get_shared_state(p_token uuid)
returns jsonb
language sql
security definer
set search_path = public
as $$
  select data from app_state
  where share_token = p_token and share_enabled = true
  limit 1;
$$;
grant execute on function get_shared_state(uuid) to anon;

如果你之前已經建立過 app_state 資料表（還沒有分享功能），改執行這段補上分享功能就好，不用整張表重建： 

alter table app_state add column if not exists share_token uuid;
alter table app_state add column if not exists share_enabled boolean not null default false;

create or replace function get_shared_state(p_token uuid)
returns jsonb
language sql
security definer
set search_path = public
as $$
  select data from app_state
  where share_token = p_token and share_enabled = true
  limit 1;
$$;
grant execute on function get_shared_state(uuid) to anon;
